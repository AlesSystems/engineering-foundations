# Curated Resources

These are starting points, not a completion checklist. Pick the section needed for the current week's questions.

## Hardware and systems

- [Nand2Tetris](https://www.nand2tetris.org/) — a project-based path from logic gates through a working computer and software stack.
- [Computer Systems: A Programmer's Perspective](https://csapp.cs.cmu.edu/) — connects programs to machine representation, architecture, linking, memory, processes, and networks.
- [Operating Systems: Three Easy Pieces](https://pages.cs.wisc.edu/~remzi/OSTEP/) — free book organized around virtualization, concurrency, and persistence.
- [MIT 6.S081: Operating System Engineering](https://pdos.csail.mit.edu/6.S081/) — lectures and labs built around xv6.

## Networking and the web

- [Beej's Guide to Network Concepts](https://beej.us/guide/bgnet0/) — approachable conceptual introduction.
- [Beej's Guide to Network Programming](https://beej.us/guide/bgnet/) — practical socket programming.
- [RFC 1122: Requirements for Internet Hosts](https://www.rfc-editor.org/rfc/rfc1122) — foundational host-layer requirements; use selectively.
- [HTTP Semantics, RFC 9110](https://www.rfc-editor.org/rfc/rfc9110) — authoritative HTTP semantics.
- [TLS 1.3, RFC 8446](https://www.rfc-editor.org/rfc/rfc8446) — authoritative protocol specification; begin with the overview and handshake sections.

## Databases and distributed systems

- [PostgreSQL documentation: Internals](https://www.postgresql.org/docs/current/internals.html) — entry point into a production relational database's internals.
- [PostgreSQL documentation: Concurrency Control](https://www.postgresql.org/docs/current/mvcc.html) — transactions, isolation, locking, and MVCC.
- [MIT 6.5840: Distributed Systems](https://pdos.csail.mit.edu/6.824/) — lectures, primary papers, and substantial labs on fault tolerance, replication, and consistency.
- [Raft paper](https://raft.github.io/raft.pdf) — an accessible consensus algorithm and a useful exercise in reading systems papers.

## Security and operations

- [OWASP Application Security Verification Standard](https://owasp.org/www-project-application-security-verification-standard/) — concrete application-security requirements.
- [NIST Cybersecurity Framework](https://www.nist.gov/cyberframework) — a broad structure for managing cybersecurity risk.
- [Google SRE books](https://sre.google/books/) — free books on reliability, SLOs, monitoring, incidents, and production practices.

## Agentic engineering

- [Attention Is All You Need](https://arxiv.org/abs/1706.03762) — the original Transformer paper; use supporting explanations before diving into every detail.
- [OpenAI API documentation](https://platform.openai.com/docs/) — current primary documentation for model capabilities, tools, structured outputs, and evaluation workflows.
- [OWASP Top 10 for LLM Applications](https://owasp.org/www-project-top-10-for-large-language-model-applications/) — a starting taxonomy for agent and LLM security risks.

## How to add a resource

Add a source only when it supports an active question. Note which chapter or section mattered and link it from the relevant topic note.
